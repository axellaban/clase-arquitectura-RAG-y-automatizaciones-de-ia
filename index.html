Tres conceptos que se confunden

En este programa construimos las tres capas. Saber dónde está parado cada cosa evita confusión.

⚙️ Automatización 🤖 Automatización con AI 🧠 Agente IA
Definición Ejecuta tareas predefinidas con reglas fijas Llama a un LLM via API en uno o más pasos Realiza tareas no-determinísticas de forma autónoma
Base lógica Lógica booleana (if/then) Booleana + razonamiento flexible Razonamiento + autonomía
Fortaleza Rápido, confiable, predecible Maneja complejidad y reconocimiento de patrones Adaptable a variables nuevas, razona como humano
Debilidad No se adapta. Solo hace lo que fue programado. Más difícil de depurar e interpretar Menos predecible, puede producir resultados inesperados
Ejemplo Notificación en Slack cada vez que entra un lead Clasificar y puntuar cada lead con un LLM Investigar el lead, actualizar el CRM y redactar el email de seguimiento
En esta clase vemos cómo combinar pasos fijos (Automatización con AI) y decisiones autónomas (Agente IA) — sumando RAG, herramientas e intervención humana (HITL) en ambos casos. n8n orquesta las tres capas.
BLOQUE 0 · 5 MIN

El Paradigma de la Alucinación

Ya tenés un agente con rol y personalidad. El problema aparece cuando tiene que responder algo específico de tu negocio.

88%
de los equipos que usaron IA sin RAG en producción reportaron al menos un error crítico de datos en el primer mes.
3x
más tiempo tarda un equipo en limpiar un error de alucinación en producción que en prevenirlo con RAG desde el principio.
$0
cuesta agregar RAG con NotebookLM o Gemini File Search sobre un agente que ya tenés. El costo de no hacerlo es otro número.
El problema: La IA generativa sin contexto propio inventa — con el mismo tono seguro y convincente que cuando tiene razón. En un proceso real, eso no es un bug menor: es un problema de confianza que se paga caro.

Fuentes: (88%) Gartner AI in Production Survey 2024 — "AI Hallucination Incidents in Enterprise Deployments"; (3×) Databricks "Long Context RAG Performance of LLMs" — análisis de tiempo de corrección vs. prevención; ($0) Google AI Developer Blog, nov. 2025 — Google File Search API pricing.

Sin RAG vs. Con RAG

❌ Agente SIN RAG

  • Memoria general: datos viejos o genéricos
  • Alucinación: inventa precios y reglas
  • Sin respaldo: no cita ninguna fuente
  • Riesgo alto: pierde confianza del cliente

✅ Agente CON RAG

  • Tus documentos: lee manuales antes de hablar
  • Honesto: avisa cuando no sabe y deriva
  • Verificable: cita documento y sección exacta
  • Siempre al día: actualizás el PDF y listo
Regla de oro: Si el dato no está en los documentos → reconocer que no sabe y derivar a una persona (HITL).

Guardrails y Costo de Producción

Prohibido para el bot

  • Confirmar datos fuera de las fuentes
  • Inventar descuentos, links o promesas
  • Seguir hablando cuando el humano tomó el chat

Obligatorio siempre

  • Respuestas breves (3–4 líneas para celular)
  • Decir "No tengo esa info" cuando falta el dato
  • Pasar todo el historial al humano en Chatwoot

BLOQUE 3 · SKILLS, HERRAMIENTAS Y MCP · 15 MIN

Cómo enseñarle y conectarlo

1. Skill

Guía reutilizable

Instrucciones paso a paso para hacer bien una tarea.

Ej: Redactar respuestas claras en 4 líneas.

2. Herramienta

Acción puntual

Función que el asistente activa en otro sistema.

Ej: Consultar stock o agendar en Calendar.

3. Conexión MCP

Enchufe universal

Estándar para conectar múltiples herramientas y datos.

Ej: Conectar n8n con Sheets, Notion o CRM.
Clave: Skill = cómo trabajar (instrucciones) · Herramienta = qué acción ejecuta · MCP = el puente de conexión.

BLOQUE 4 · ELEGIR Y COMPROBAR · 10 MIN

Elegir el flujo y hacer las 3 pruebas

Pasos fijos (Reglas + IA)

Camino A → B → C fijo. La IA solo redacta o clasifica. Ideal para procesos repetitivos y predecibles. Admite HITL.

Flujo agéntico (El agente decide)

El agente elige qué fuente o herramienta usar según la pregunta abierta del cliente. Admite HITL.

Prueba 1 Dato en Fuente A

Verificar respuesta exacta + cita del documento.

Prueba 2 Dato en Fuente B / Sheet

Confirmar que elige la fuente correcta sin mezclar.

Prueba 3 · Clave Dato que NO existe

Comprobar que no inventa y deriva a humano (HITL).

Chequeo final: ¿Verdadero o Falso?

Avanzá con la flecha (→) para revelar cada respuesta.

Afirmación Respuesta Por qué
1. Un RAG reduce las alucinaciones al consultar documentos antes de responder. Verdadero Reduce el riesgo con fuentes reales; si no está el dato, debe avisar y derivar.
2. Probar en NotebookLM reemplaza probar el bot en WhatsApp o Telegram. Falso NotebookLM valida los documentos; después hay que probar el bot en el canal real.
3. Un flujo puede tener pasos fijos y usar IA para redactar una respuesta. Verdadero Usar IA para redactar no lo vuelve agéntico; el agente es el que decide qué herramientas usar.
4. Una Skill y una conexión MCP cumplen la misma función. Falso La Skill da instrucciones para una tarea; MCP conecta con herramientas y datos.
5. HITL permite que una persona revise o continúe una charla cuando hace falta. Verdadero En Chatwoot recibe todo el historial, toma el control y el bot se pausa.
